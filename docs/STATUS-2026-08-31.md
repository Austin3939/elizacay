## 2. Other features that should be included

Not blocking a soft launch, but on the roadmap — several are core to the site's stated
audience-building strategy in `ProjectOverview.md`.

- **Process Journal** — was built then removed. The whole "flywheel" strategy (`ProjectOverview.md`)
  depends on it. Decision needed: reinstate as static data file (`src/data/journal.js` pattern,
  ~1 hr) or CMS-backed (Directus-on-Pi spec exists at `docs/superpowers/specs/` era notes).
- **Analytics** — Plausible or GA4, to measure the shop → subscribe → buy funnel.
  *(Deferred — awaiting platform choice.)*
- **Print edition tracking** — "12 of 50 remaining" style scarcity UI, if prints are limited edition.
  *(Deferred — needs open-vs-limited decision + a Shopify metafield for edition size/sold count.)*
- **Abandoned-cart + welcome email automations** — via the chosen email platform (Klaviyo integrates
  with Shopify natively). *(Not repo code — email-platform config.)*
- **Commission reference-image upload** — deferred until the form delivers (Formspree handles uploads).

### Done in the 2026-08-31 polish pass

- **SEO** — lightweight `<Seo>` component (`src/components/Seo.jsx`) sets per-page title / description /
  canonical / OpenGraph / Twitter tags; `vite.config.js` prerenders `/ /gallery /shop /commission

- **Commission honeypot** — hidden `company` field + <3s submit-time trap in `Commission.jsx`
  (inert until form delivery is wired).

- **A11y / mobile pass** — skip-to-content link, global `:focus-visible` outlines, visually-hidden

  handling, `.sr-only` utility.
